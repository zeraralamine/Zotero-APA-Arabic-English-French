# Zotero-APA-Arabic-English-French
This custom CSL file is designed to be the first proper Zotero style for Arabic citations. Because Zotero is natively built for Left-to-Right (LTR) languages, Arabic citations usually suffer from broken parentheses and mixed-up punctuation.

This style solves the RTL (Right-to-Left) formatting issues and automatically uses correct Arabic terminology (like "وآخرون" instead of "et al." and "و" instead of "and").

How to Use:

1. Download the code from this repository and save it as a .csl file (e.g., apa-arabic.csl).
2. Open Zotero.
3. Go to Edit > Preferences (Windows/Linux) or Zotero > Settings (Mac).
4. Go to the Cite tab, then select the Styles section.
5. Click the + (plus) button and upload your .csl file.

Important: To trigger the correct Arabic formatting and terms, you must type ar into the Language field of your Arabic reference items in Zotero. (Use en for English and fr for French).
